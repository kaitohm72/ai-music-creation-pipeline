# AI Music Studio — Songwriting Workflow Prototype

AI Music Studio is a personal project by an independent developer based in Japan and an active annual Suno Premier subscriber. Built with Python and Google Cloud Run Jobs, it is intended to support original multilingual songwriting in Chinese, English, and Japanese.

The system drafts and refines lyrics, evaluates lyric quality and singability, and prepares detailed music-style prompts. The creator reviews and refines the lyrics and prompts before submission.

## Planned Suno API use

The project is seeking access to Suno's official API. If access is approved, I plan to submit approximately three song-generation requests per day for music generation, in accordance with Suno's API terms, usage limits, and pricing. API approval and integration are pending; neither is currently in place.

If supported by the API, I would like generated songs to appear in my existing Suno account Library for listening and manual downloading. I do not plan to automate audio downloads or distribution, provide API access to other users, or operate a public API service.

## Originality and responsible use

This workflow is intended to support original works. It is not intended to imitate existing songs, artists, or voices, or to submit material without the necessary rights.

This is an independent project and is not affiliated with or endorsed by Suno.
