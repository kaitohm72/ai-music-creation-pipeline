# AI Music Studio — Songwriting Workflow Prototype

AI Music Studio is a personal prototype for developing original songs in Chinese, English, and Japanese. It helps turn a creative brief into draft lyrics and music prompts.

The planned workflow calls for the creator to review and refine lyrics and prompts before submission. The project is seeking access to Suno's API. If access is approved, it plans to submit creator-reviewed lyrics and prompts through Suno's official API, subject to the API's terms and rate limits, with no more than three song submissions per day. API approval and integration are pending; neither is currently in place.

The workflow is intended to support original works and avoid imitating existing songs, artists, or voices, or submitting material without the necessary rights.

The project owner is an active paid Suno subscriber.

This is an independent project and is not affiliated with or endorsed by Suno.
