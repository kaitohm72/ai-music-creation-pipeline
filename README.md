# AI Music Studio — Songwriting Workflow Prototype

AI Music Studio is an independent personal prototype for developing original songs intended to support Chinese, English, and Japanese.

The project is seeking access to Suno's API. If access is approved, the planned workflow will submit generated lyrics and music prompts directly to Suno through the API. API approval and this direct submission workflow are pending and are not currently implemented. The planned limit is no more than three song submissions per day.

The project owner is a Suno Premium member.

The project focuses on songwriting materials and encourages original themes and avoiding copying existing lyrics or melodies.

This is an independent project and is not affiliated with or endorsed by Suno.
