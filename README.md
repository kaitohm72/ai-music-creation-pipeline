# AI Music Studio — Songwriting Workflow Prototype

AI Music Studio is a personal prototype for developing original Chinese-language songs. It turns a creative brief into draft lyrics and an English music-generation prompt intended for use with Suno, then applies structured review and revision to improve clarity, singability, and consistency.

The project focuses on songwriting materials. It does not connect directly to Suno, generate audio, or upload or distribute music. Its workflow is designed to encourage original themes and avoid copying existing lyrics or melodies.

This is an independent project and is not affiliated with or endorsed by Suno.
